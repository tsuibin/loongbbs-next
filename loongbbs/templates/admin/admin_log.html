Instructions for limiting view/prune access to the admin log.

Access control to the admin log is not controlled through the control panel for security reasons.
In vBulletin access is controlled by two variables ($canviewadminlog / $canpruneadminlog) placed in admin/config.php, each taking one userid or a comma separated list of userids.

This board has no admin/config.php: the log is written for every administrator action, and the log viewer / prune forms are available to any member of the Administrator usergroup.
