什么是 vB 代码？

vB 代码是一组标签，语法比 HTML 简单，用来给帖子加格式，但永远不会破坏页面版式。某个版块能不能用 vB 代码由管理员按版块设置，发帖前请先看版块规则。

超链接

只要在正文里写完整网址，链接会自动生成；以 www. 开头时不必加 http://。也可以自己加标签：

[url]www.vbulletin.com/forum/[/url]

要显示说明文字而不是网址本身，用带等号的形式：

[url=http://www.vbulletin.com/forum/]点击访问 vBulletin 论坛[/url]

效果：点击访问 vBulletin 论坛。

邮箱链接

[email]myname@domain.com[/email]

也可以写成带说明的形式：

[email=myname@domain.com]给我写信[/email]

粗体、下划线、斜体

  • [b]文本[/b] → 文本
  • [u]文本[/u] → 文本
  • [i]文本[/i] → 文本

颜色、字号与字体

  • [color=blue]文本[/color] → 文本
  • [size=4]文本[/size] → 文本
  • [font=courier]文本[/font] → 文本

这些可以叠加使用：

[color=purple][u][b]哇，这么多格式！[/b][/u][/color]

哇，这么多格式！

列表

[list]
[*]第一项
[*]第二项
[/list]

效果：

  • 第一项
  • 第二项

编号列表用 [list=1]，字母列表用 [list=A]。

插入图片

[img]http://www.example.com/图片地址.gif[/img]

地址必须带 http://；还可以把 [img] 套进 [url] 做成点击放大的缩略图。

引用

[quote]别试。
要么做，要么不做，没有“试试看”。[/quote]

[quote] 里的文字会自动缩进显示。

代码与 PHP 标签

贴程序源码或 ASCII 画时，用 [code]：内容按等宽字体显示、空格原样保留。

[code]
<script language="Javascript">
alert("Hello world!");
</script>
[/code]

PHP 代码用 [php]，会按 PHP 语法着色显示（本项目按代码块原样呈现）。

常见错误

  • [url] www.vbulletin.com [/url] —— 标签与内容之间不要留空格。
  • [email]myname@domain.com[email] —— 结束标签要带斜杠：[/email]。
